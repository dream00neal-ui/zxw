# 我的人脉商机 · 高保真原型（中项网）

单文件 HTML 原型（Tailwind CDN + 原生 JS），按版本分两个页面：

- **我的人脉商机-尊享版.html** —— 尊享版：人脉商机流（多路径聚合）+ 全部人脉 + 可能认识的人
- **我的人脉管理-标准版.html** —— 标准版：人脉资产管理 + 合作人脉 + 穿透项目（限量）+ 升级钩子

访问 `index.html`（**版本切换演示入口**：同一页面内切换 尊享版 ↔ 标准版，GitHub Pages 首页同此）或双击对应文件单独体验。

## 内容
- **人脉商机**（默认页）：人脉解锁的项目流——直接/间接人脉筛选、发布时间/行业/地区/项目阶段/投资金额下拉筛选、路径链、查看详情/收藏
- **全部人脉**：联系人+公司统一资产列表（类型/来源筛选、价值排序），顶部"可能认识的人"推荐条
- **场景演示**（右下角 🎬）：项目详情/企业详情/工程人脉查询三个真实页面模拟，「标记合作」→写入资产→解锁商机的完整闭环
- docgen/：配套 PRD 文档源文件与打包脚本

## 说明
- `index.html` 是 `我的人脉商机-尊享版.html` 的发布副本（GitHub Pages 需要英文入口文件），两者内容一致
- 原型数据为演示数据，刷新即重置
