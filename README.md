# 我的人脉商机 · 高保真原型（中项网）

单文件 HTML 原型（Tailwind CDN + 原生 JS），双击 `我的人脉.html` 或访问 GitHub Pages 即可体验。

## 内容
- **我的人脉商机**（默认页）：人脉解锁的项目流——直接/间接人脉筛选、发布时间/行业/地区/项目阶段/投资金额下拉筛选、路径链、查看详情/收藏
- **全部人脉**：联系人+公司统一资产列表（类型/来源筛选、价值排序），顶部"可能认识的人"推荐条
- **场景演示**（右下角 🎬）：项目详情/企业详情/工程人脉查询三个真实页面模拟，「标记合作」→写入资产→解锁商机的完整闭环
- docgen/：配套 PRD 文档源文件与打包脚本

## 说明
- `index.html` 是 `我的人脉.html` 的发布副本（GitHub Pages 需要英文入口文件），两者内容一致
- 原型数据为演示数据，刷新即重置
